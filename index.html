Assistente pessoal de uso privado. Não é um produto público: só o próprio titular da conta usa este aplicativo, que roda no computador dele.

Política de privacidade

Quem usa: apenas o titular da conta Google que autorizou o acesso. Ninguém mais é cadastrado ou atendido.

Quais dados: com autorização explícita do titular, o aplicativo lê e gerencia dados da própria conta Google dele: e-mail (Gmail), agenda, Drive, Documentos, Planilhas e contatos.

Para quê: exclusivamente para ajudar o titular a organizar a rotina dele: resumir e-mails, consultar a agenda e localizar ou editar os próprios arquivos. O envio de e-mails e a alteração de arquivos só acontecem com aprovação dele.

Onde ficam: o token de acesso e os dados consultados ficam no computador do titular. Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade ou para treinar modelos de IA.

Como revogar: o titular pode remover o acesso a qualquer momento em myaccount.google.com/permissions.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.
